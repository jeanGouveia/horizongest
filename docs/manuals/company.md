### Access

- **Login URL:** `https://platform.com/signin`

- **Password:** Set during account creation

## Company Settings

### Overview

Company settings control your business configuration and branding.

### Access

Navigate to: **Settings → Company Settings**

### Configuration Options

#### Basic Information
- **Company Name:** Your restaurant name
- **Document:** Legal document (CNPJ, Tax ID)
- **Email:** Contact email
- **Phone:** Contact phone
- **Address:** Business address

#### Business Hours
- **Opening Time:** When your restaurant opens
- **Closing Time:** When your restaurant closes
- **Days of Operation:** Which days you're open

#### Branding
- **Logo:** Your restaurant logo
- **Colors:** Brand colors
- **Theme:** Visual theme

#### Localization
- **Timezone:** Your local timezone
- **Locale:** Language/locale

### Best Practices

- Keep company information up to date
- Use high-quality logo images
- Set accurate business hours
- Configure timezone correctly

## User Management

### Overview

User management allows you to manage your team members and their access.

### Access

Navigate to: **Users → Team Members**

### Creating Users

1. Click **"New User"**
2. Fill in user information:
   - Name
   - Email
   - Role (Manager, Employee, Viewer)
3. Click **"Send Invite"**
4. User will receive an email with setup instructions

### Roles

#### Manager
- Full access to all features
- Can manage users
- Can configure settings
- Can view all reports

#### Employee
- Access to operational features
- Can manage orders
- Can manage inventory
- Cannot manage users or settings

#### Viewer
- Read-only access
- Can view reports
- Cannot modify data

### Managing Users

- **View:** View user details
- **Edit:** Modify user information
- **Deactivate:** Disable user access
- **Delete:** Remove user (with confirmation)

### Best Practices

- Use principle of least privilege
- Regularly review user access
- Remove access for former employees
- Use strong password policies

## Menu Management

### Overview

Menu management allows you to create and manage your restaurant's menu items.

### Access

Navigate to: **Menu → Products**

### Creating Products

1. Click **"New Product"**
2. Fill in product information:
   - Name
   - Description
   - Category
   - Price
   - Currency
   - Image
   - Status (Active, Inactive)
3. Click **"Create"**

### Product Categories

Categories help organize your menu. Common categories:
- Appetizers
- Main Courses
- Desserts
- Beverages
- Sides

### Managing Products

- **View:** View product details
- **Edit:** Modify product information
- **Activate/Deactivate:** Enable or disable product
- **Delete:** Remove product (with confirmation)

### Best Practices

- Use high-quality product images
- Write clear descriptions
- Set appropriate prices
- Organize products into categories
- Regularly update menu

## Order Management

### Overview

Order management allows you to track and manage customer orders.

### Access

Navigate to: **Orders → All Orders**

### Order Status

Orders can have the following statuses:
- **Pending:** Order received, not yet processed
- **Preparing:** Order is being prepared
- **Ready:** Order is ready for pickup/delivery
- **Delivered:** Order has been delivered
- **Cancelled:** Order was cancelled

### Managing Orders

- **View:** View order details
- **Update Status:** Change order status
- **Cancel:** Cancel an order (with reason)
- **Refund:** Process a refund (if applicable)

### Best Practices

- Process orders promptly
- Communicate status changes
- Handle cancellations professionally
- Monitor order trends

## Inventory Management

### Overview

Inventory management allows you to track ingredients and stock levels.

### Access

Navigate to: **Inventory → Stock**

### Creating Ingredients

1. Click **"New Ingredient"**
2. Fill in ingredient information:
   - Name
   - Category
   - Unit (kg, g, L, ml, units)
   - Current Stock
   - Minimum Stock
   - Cost per Unit
3. Click **"Create"**

### Stock Movements

Track stock movements:
- **In:** Stock added (purchases, returns)
- **Out:** Stock removed (usage, waste)
- **Adjustment:** Manual adjustments

### Low Stock Alerts

Set minimum stock levels to receive alerts when stock is low.

### Best Practices

- Regularly update stock levels
- Track all movements
- Set appropriate minimum stock levels
- Review inventory reports
